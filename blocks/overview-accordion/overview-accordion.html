• Proactive

    Our remote I/Os feature event-driven push and Click&Go Plus Logic to move beyond polling, reducing host reliance and streamlining IT/OT integration.

    Event-driven push technology

    With push-type communication, remote I/Os send data only when changes occur, significantly reducing unnecessary network traffic. Unlike pull-based systems that constantly poll devices, this method enables faster system responses and lowers overall bandwidth usage. More importantly, by offloading routine data handling from the host system, push communication helps free up computing resources, allowing the upper system to focus on higher-level applications and real-time analysis.


    Supported Models:
    ioLogik E1200 Series, ioLogik 2500 Series, MX-AOPC UA Suite

    Intuitive Click&Go Plus logic

    Moxa’s Click&Go Plus Logic enables smart, front-end control logic by executing event-based actions directly on the device—eliminating the need for constant communication with a host. You can configure logic rules using an intuitive graphical interface with simple if-then-else conditions. By processing logic at the edge, devices react instantly to field events and reduce host dependency to boost overall efficiency.


    Supported Models: ioLogik 2500 Series

  • Easy to Use

    Effortless setup with front wiring and daisy-chained Ethernet simplifies installation and lowers effort, cost, and complexity.

    Front-wiring design

    The front-facing wiring design makes installation easier and more efficient by allowing direct access to terminals. This design not only simplifies wiring but also helps save over 50% of the required DIN-rail installation space, making it ideal for compact control panels.


    Supported Models:
    ioLogik E1200 Series, ioLogik R1200 Series, ioLogik 2500 Series, ioThinx 4510 Series

    Dual LAN ports for daisy-chain networks

    With two built-in LAN ports, devices can be directly connected in a daisy-chain configuration without needing an external switch. This simplifies network architecture, reduces wiring complexity, and lowers both installation time and costs.


    Supported Models: ioLogik E1200 Series, ioThinx 4510 Series

    User-defined Modbus address

    The ability to modify Modbus addresses allows the device to fit easily into existing systems without requiring major changes to configurations. This flexibility reduces implementation effort, minimizes downtime, and ensures smoother integration with legacy equipment.


    Supported Models: ioLogik E1200 Series, ioLogik 2500 Series, ioThinx 4510 Series
